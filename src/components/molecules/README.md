# Molecules

Molecules combine atoms into reusable interface components.

Current molecules:

- `Button`: button variants, icons, sizes, and states.
- `TextField`: label, helper text, validation, icons, tooltip, and input variants.
- `Tooltip`: helper icon trigger with hover and focus popover behavior.

Molecules may use atoms, icons, and design tokens. They should stay reusable and should not know about a full page or application workflow.
