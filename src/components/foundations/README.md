# Foundations

Foundation components document design tokens in Storybook.

Current foundation groups:

- `Colors`: color token documentation.
- `Spacing`: size scale token documentation (`SpacingScale` component).
- `Shadows`: elevation token documentation.
- `Typography`: text scale and weight primitives.

The token source files live in `src/styling/theme`. This folder contains the Storybook-facing React components that display those tokens.
